# حارس الحساسية

تطبيق Android عربي لتسجيل الأدوية والحساسيات الدوائية والغذائية، مع حفظ البيانات محليًا، إدارة السجلات، إنشاء بطاقة طوارئ، وتصدير البيانات إلى PDF أو Excel/CSV.

## ما يعمل في النسخة الحالية — v0.4.0

- واجهة عربية من اليمين إلى اليسار.
- إضافة دواء / علاج عادي مع الاسم والمادة الفعالة والاستخدام أو الملاحظات.
- إضافة حساسية دوائية مع الأعراض وشدة التفاعل.
- إضافة حساسية غذائية.
- إضافة دواء تم تحمّله دون حساسية.
- حفظ البيانات تلقائيًا على الجهاز باستخدام AsyncStorage.
- شاشة سجلات كاملة مع التصفية حسب النوع.
- **عرض تفاصيل أي سجل**.
- **تعديل أي سجل محفوظ**.
- **حذف أي سجل بعد رسالة تأكيد**.
- **إضافة سجل جديد مباشرة من شاشة السجلات**.
- **تصدير جميع السجلات إلى PDF عربي قابل للمشاركة**.
- **تصدير جميع السجلات إلى CSV متوافق مع Excel**.
- بطاقة طوارئ تلخص الحساسية، الأدوية المسجلة، والأدوية المتحملة.
- تعديل بيانات الشخص ومشاركة بطاقة الطوارئ عبر قائمة المشاركة في Android.
- تصدير نسخة احتياطية JSON مشفرة بكلمة مرور.
- استيراد النسخة المشفرة بعد التحقق من كلمة المرور وسلامة الملف، مع تأكيد صريح قبل الاستبدال.
- تشفير النسخ باستخدام PBKDF2-SHA256 لاشتقاق المفتاح وXSalsa20-Poly1305 لحماية المحتوى.
- فحص تحديثات GitHub من داخل التطبيق.
- GitHub Actions يبني APK مباشرة باستخدام Expo Prebuild + Gradle بدون الحاجة إلى EAS أو EXPO_TOKEN.

## التشغيل المحلي

```bash
pnpm install
pnpm check
pnpm start
```

يمكن فتح المشروع عبر Expo أو تشغيله على محاكي Android متصل.

## إدارة السجلات

من تبويب **السجلات الصحية** يمكنك:

- الضغط على **إضافة سجل** لإضافة دواء أو حساسية.
- استخدام الفلاتر لعرض كل السجلات أو نوع محدد.
- الضغط على **عرض** للاطلاع على جميع تفاصيل السجل.
- الضغط على **تعديل** لتعديل السجل وحفظ التغييرات.
- الضغط على **حذف** لحذف السجل بعد تأكيد العملية.
- الضغط على **PDF** لإنشاء ملف PDF يحتوي جميع السجلات وبيانات المستخدم ثم فتح قائمة المشاركة.
- الضغط على **Excel** لإنشاء ملف CSV بترميز UTF-8 قابل للفتح في Excel وGoogle Sheets.

## النسخ الاحتياطي والاستعادة

من تبويب **بطاقة الطوارئ** استخدم قسم **النسخ الاحتياطي**:

- **تصدير مشفر:** ملف `.agbackup` كامل محمي بكلمة مرور من 8 أحرف أو أكثر.
- **تصدير Excel:** ملف CSV بترميز UTF-8 مع BOM.
- **استيراد مشفر:** اختر ملف `.agbackup` وأدخل كلمة المرور ثم أكد الاستبدال.

يتم إنشاء ملفات التصدير محليًا ثم فتح قائمة مشاركة Android. لا تُرفع النسخة الاحتياطية إلى خادم التطبيق.

## بناء APK عبر GitHub Actions

الـ workflow باسم **Android preview APK** يقوم تلقائيًا بـ:

1. تثبيت الحزم.
2. تشغيل TypeScript check.
3. تشغيل Expo Prebuild لإنشاء مشروع Android.
4. إعداد Java 17.
5. بناء APK باستخدام Gradle.
6. رفع `allergy-guard-android.apk` كـ GitHub Artifact.
7. عند دفع tag يبدأ بـ `v` يتم أيضًا إنشاء GitHub Release وإرفاق APK.

مثال:

```bash
git tag v0.4.0
git push origin v0.4.0
```
