# حارس الحساسية

تطبيق Android عربي لتسجيل مسببات الحساسية من الأدوية والأطعمة، مع حفظ البيانات محليًا وإنشاء بطاقة طوارئ قابلة للمشاركة.

## تحديثات GitHub الآمنة

يتحقق التطبيق تلقائيًا من أحدث إصدار مستقر في GitHub عند التشغيل والعودة إلى مقدمة التطبيق، وبفاصل لا يتجاوز مرة كل 12 ساعة. يقبل فقط إصدارًا أحدث، ويستبعد الإصدارات التجريبية، ويتحقق من أن رابط APK يستخدم HTTPS ومن نطاق GitHub الرسمي.

عند العثور على تحديث، يعرض التطبيق رسالة للمستخدم ثم يفتح رابط APK الرسمي. لا يسمح Android بالتثبيت الصامت من داخل التطبيق؛ يجب أن يوافق المستخدم على التنزيل والتثبيت عبر نظام Android. ملفات APK الأصلية تُبنى عبر EAS وتُرفع إلى GitHub Releases، ولا تُضمّن أسرار Expo داخل الشيفرة.

## ما يعمل في النسخة الحالية — v0.3.0

- واجهة عربية من اليمين إلى اليسار.
- إضافة دواء سبب حساسية مع الاسم التجاري والمادة الفعالة والاستخدام والأعراض وشدة التفاعل.
- إضافة طعام أو مكوّن سبب حساسية.
- إضافة دواء تم تحمّله دون ظهور أعراض.
- حفظ البيانات تلقائيًا على الجهاز باستخدام AsyncStorage.
- دفتر سجلات مع التصفية والحذف.
- بطاقة طوارئ تلخص الحساسية والأدوية المتحملة.
- تعديل بيانات الشخص ومشاركة بطاقة الطوارئ عبر قائمة المشاركة في Android.
- تصدير نسخة احتياطية JSON مشفرة بكلمة مرور، أو CSV متوافق مع Excel.
- استيراد النسخة المشفرة بعد التحقق من كلمة المرور وسلامة الملف، مع تأكيد صريح قبل الاستبدال.
- تشفير النسخ باستخدام PBKDF2-SHA256 لاشتقاق المفتاح وXSalsa20-Poly1305 لحماية المحتوى.
- اختبارات وحدة للتصدير JSON وCSV، والاستيراد، وفك التشفير، وكلمات المرور الخاطئة والملفات المعدلة.
- إعداد EAS وإجراء GitHub Action لبناء APK تجريبي عند تشغيل workflow يدويًا أو دفع tag يبدأ بـ `v`.

## التشغيل المحلي

```bash
pnpm install
pnpm check
pnpm start
```

يمكن فتح المشروع عبر Expo Go أو تشغيله على محاكي Android متصل.

## النسخ الاحتياطي والاستعادة

من تبويب **بطاقة الطوارئ** استخدم قسم **النسخ الاحتياطي**:

- **تصدير مشفر:** ملف `.agbackup` كامل محمي بكلمة مرور من 8 أحرف أو أكثر. لا تفقد كلمة المرور؛ لا يمكن استعادة الملف بدونها.
- **تصدير Excel:** ملف CSV بترميز UTF-8 مع BOM، يفتح مباشرة في Excel وGoogle Sheets.
- **استيراد مشفر:** اختر ملف `.agbackup` وأدخل كلمة المرور، ثم راجع عدد السجلات وأكد الاستبدال.

يتم إنشاء ملفات التصدير محليًا ثم فتح قائمة مشاركة Android. لا تُرفع النسخة الاحتياطية إلى خادم التطبيق. ملف CSV غير مشفر ومخصص للعرض في Excel، لذلك لا تشاركه إلا عبر قناة موثوقة.

## بناء APK عبر GitHub Actions

1. أنشئ حسابًا أو مشروعًا في Expo/EAS.
2. أنشئ token من حساب Expo.
3. أضف السر في GitHub باسم `EXPO_TOKEN` من إعدادات المستودع.
4. شغّل workflow باسم **Android preview APK** يدويًا، أو ادفع tag مثل:

```bash
git tag v0.1.0
git push origin v0.1.0
```

ينّتج البناء ملف APK تجريبيًا عبر EAS. لا تضع أي token داخل المستودع أو ملفات التطبيق.

## ملاحظات طبية

هذا التطبيق أداة تنظيم معلومات شخصية وليس أداة تشخيص أو وصف علاج. تسجيل دواء على أنه تم تحمّله لا يضمن سلامته مستقبلًا؛ يجب التأكد من الطبيب أو الصيدلي في كل مرة.
